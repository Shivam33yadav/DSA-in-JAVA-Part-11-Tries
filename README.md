# DSA in Java – Part 11: Tries

This repository contains my Java implementations and problem-solving practice focused on **Trie Data Structure**, an efficient tree-based data structure used for storing and searching strings.

## 📚 Topics Covered

- Introduction to Trie Data Structure
- Trie Node Implementation
- Trie Insertion
- Trie Search
- Trie Prefix Search
- Starts With Operation
- Word Deletion in Trie
- Counting Words and Prefixes
- Longest Word with All Prefixes
- Word Break Problem
- Unique Prefix Problem
- Practice Problems Based on Tries

## 🛠️ Technologies Used

- **Language:** Java
- **IDE:** VS Code
- **Concepts:** Trie, Trees, Strings, Recursion, Prefix Searching

## 🎯 Learning Objectives

- Understand the structure and working of Trie.
- Implement insertion and searching operations.
- Learn efficient prefix-based searching.
- Solve string-related problems using Trie.
- Improve problem-solving and algorithmic thinking.
